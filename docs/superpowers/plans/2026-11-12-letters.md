**Goal:** Reliable, evidence-grounded letter drafting in the existing app.
**Architecture:** Plain-text prompt templates and pure prompt builders; Streamlit session state holds per-path inputs and editable drafts. Groq is called only on explicit generation.

**Spec:** docs/superpowers/specs/2026-11-12-letters-design.md

Preserve acknowledgement copy and practice details. No patient data persisted to disk or shared cache. No automatic API calls. No new workflow or provider migration.
